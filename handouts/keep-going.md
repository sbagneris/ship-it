## 4. Running it on your own computer

Three steps, and it's fine to ask a grown-up for help with the first one:

1. Install Python from [python.org](https://python.org)
2. Open a terminal in your project folder and run: `pip install flask`
3. Run: `flask run`

Then open **http://localhost:5000** in your browser. That's your site, running on your own machine.

> One thing that won't work: the AI feature uses your teacher's server, which turns off when the class ends. Everything else works.
