# Credential Card

Print one per student. Cut along the lines. **Print four spares** — someone will lose theirs in week two, and someone else in week five.

---

```
┌──────────────────────────────────────────────┐
│                                              │
│   SHIP IT                                    │
│                                              │
│   Your website                               │
│   ada.class.example.dev                      │
│                                              │
│   Where you write the code                   │
│   code-ada.class.example.dev                 │
│                                              │
│   Password                                   │
│   orange-piano-42                            │
│                                              │
│   Everybody's sites                          │
│   class.example.dev                          │
│                                              │
│   ──────────────────────────────────────     │
│   Two tabs. Always.                          │
│   Change it → save it → refresh it.          │
│                                              │
└──────────────────────────────────────────────┘
```

---

**Generate the passwords, don't invent them.** Three common words joined by dashes. A student who can't type their password is a student who isn't coding, and these guard a sandbox, not a bank.

**Put the site URL first.** It's the one they'll want to text to someone.
